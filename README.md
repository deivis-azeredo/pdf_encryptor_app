# 🔒 PDF Encryptor App

A lightweight, local web application built with **Python**, **Streamlit**, and **PyPDF** that enables users to secure PDF files with custom password protection in real-time.

---

## 🚀 Key Features

- **Document Upload:** Fast and secure upload of local `.pdf` files.
- **Custom Encryption:** Users can set custom encryption keys dynamically.
- **Real-Time Verification:** Instant status feedback upon successful encryption.
- **Protected File Download:** Instant output generation for encrypted documents.

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.10+
- **Frontend / Interface:** [Streamlit](https://streamlit.io/)
- **PDF Processing / Security:** [PyPDF](https://pypdf.readthedocs.io/)
